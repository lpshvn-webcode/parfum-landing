# KILLER PERFUME — локальный прототип

Актуальная версия — тёмная парфюмерная концепция для мужской аудитории: `noir.html`, `noir.css`, `noir.js`. Крупные брендовые флаконы, холодный и бордовый свет, интерактивная демонстрация формата сета и каталог ароматов. Главная страница открывает эту версию.

Каталог содержит 18 позиций из присланной клиентом таблицы, без аромата «Зеленский». Сначала показываются три карточки, остальные открываются кнопкой «Показать ещё». Для каждой позиции подготовлена прозрачная PNG-визуализация. Происхождение парфюмерии (оригинальная или по мотивам) клиент пока не подтвердил; утверждений об оригинальности нет.

## Запуск

Нужен Node.js 20+. В каталоге репозитория выполните `npm run dev`. Сервер работает на порту 3000, альтернативный порт задаётся через `PORT`.

- `/?offer=10` — предложение с разными сочетаниями в двух сетах.
- `/?offer=5` — подарочный сет повторяет первый.
- Панель внизу страницы переключает версии для просмотра.
- Интерактивный блок объясняет формат пяти атомайзеров, но не собирает состав заказа.

## Tilda T123

`npm run build` создаёт:

- `dist/tilda-10.html` и `dist/tilda-5.html` — содержимое для T123 (без html/head/body).
- `dist/preview-10.html` и `dist/preview-5.html` — автономные страницы для локального просмотра.

Автономные `preview-*.html` включают фото и шрифты, их можно открыть без сервера. Экспорты `tilda-*.html` включают CSS и JavaScript, а фото и шрифты лежат в `dist/assets/`: это сохраняет размер HTML-блока небольшим. Для Tilda разместите эти ресурсы по публичному HTTPS-адресу и пересоберите с `ASSET_BASE=https://your-approved-host.example/perfume npm run build`, заменив адрес реальным. По умолчанию ссылки относительные и подходят для локального сервера, но не для чужого домена Tilda. Шрифтовый хост должен разрешать CORS.

Стили ограничены контейнером `#killer-perfume`. Размещайте только один вариант на одной странице Tilda: идентификаторы общие. Для сравнения нужны две страницы с разными адресами. Перед запуском уберите `.nk-review` из исходного HTML после выбора варианта и пересоберите. У Tilda контейнер T123 должен быть на всю ширину, без внешних отступов. Проверка в самой опубликованной странице Tilda остаётся отдельным этапом.

## Текущие допущения и материалы

- Каждый сет показан как пять атомайзеров по 10 мл. Возможность повторять аромат и реальные фасовки нужно подтвердить с клиентом.
- Названия, звучание и ноты 18 ароматов взяты из таблицы клиента. Интерактивные примеры настроений не являются готовыми составами заказа.
- Изображения флаконов сгенерированы для дизайн-концепции. 18 прозрачных PNG каталога находятся в `assets/catalog/`; их исходники и происхождение описаны в `assets/SOURCES.md`. Это не фотографии реального товара. Killer, Musk Kashmir и мужской феромон используют условный дизайн, поскольку точная упаковка не предоставлена. Текстовый знак KP — временная интерпретация логотипа.
- Шрифт Manrope с лицензией OFL взят из указанного заказчиком репозитория Küchen Technik. Лицензия хранится рядом с файлами шрифта.
- Реальные отзывы, фотографии и видео не получены; отзывы и показатели доверия не выдумывались. Соответствующий блок добавляется после получения материалов.
- Условия двух акций должны быть подтверждены перед рекламой соответствующей версии.

## Приём заявок

Встроенной формы и локального приёма заявок нет. Все коммерческие CTA имеют одинаковый текст «Приобрести сет» и ведут на `#popup1`. На странице Tilda должен существовать и быть настроен соответствующий popup с формой, согласием на обработку данных и подключённым получателем заявок. В автономном предпросмотре ссылка только меняет hash — это ожидаемо. Пиксели Meta/TikTok не установлены.

## Проверка

`npm test` использует установленный в облачной среде Playwright и Chromium. Сначала запустите `npm run dev` и выполните `npm run build`. Проверяется мобильная версия 390 px, узкий экран 320 px, десктоп, два оффера, слайд-шоу, интерактивные примеры, каталог из 18 позиций, фильтры, ссылки `#popup1` и автономный T123-экспорт. Скриншоты создаются в `artifacts/`.

Готовые WebP включены в репозиторий; исходные PNG для запуска и сборки не требуются. Публикация на Tilda выполняется отдельно после согласования.
